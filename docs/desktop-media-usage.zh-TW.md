# 官方 Desktop 的圖片原件與 CMCP 狀態

這份說明適用於官方 DeepSeek Harness Desktop，以及使用者明示工作區內的 `cmcp-desktop-native` 部署。實際路徑由該部署的設定與狀態顯示；不要求特定作者家目錄。實際驗收版本與通過範圍以對應主報告及部署清單為準；這份操作說明本身不是驗收結果。

## 正常聊天與圖片保存

1. 從原本的 DeepSeek Harness Desktop 進入工作區並建立對話。輸入框下方的 CMCP 入口預設最小化。
2. 按 CMCP 小型入口，或在原生輸入區執行 `/cmcp help`，確認本對話是否加入、工作區增強與保存 User／Assistant 的有效狀態。對話加入與工作區共用控制是兩層不同操作；加入對話不會解除共用 OFF 或 Clean。
3. 在原生輸入區使用附件入口選擇 PNG 或 JPEG，並與自然文字說明一起送出。當輪原生模型確實收到圖片時，可以直接回答；這與跨 Session 正式回查分開判定。
4. 修訂圖片仍從同一原生入口提交。兩個原件分別保存檔名、媒體類型、bytes、SHA-256、User 原文、角色、Session、來源版本與原時間，不以圖片描述取代原件。
5. 新 Session 須再次明確加入 CMCP。以自然問題找回前次原圖與修訂圖；正式回查先取得 User 原文，再以該頁的媒體參照讀取圖片。不要人工重貼圖片冒充接續。

原生 Harness 聊天紀錄、CMCP 原文保存與圖片原件是不同責任。CMCP OFF 不會刪除宿主原生聊天歷史；在同一舊 Session 繼續聊天，模型仍可能看到原有對話。OFF 後不得新增 CMCP 增強材料，也不能把工具仍註冊當成來源已取得。

## 薄列與按需詳細資料

`/cmcp ui minimized` 顯示最小入口；`/cmcp ui row` 顯示一般單列；`/cmcp ui hidden` 隱藏控制列。偏好只記住此工作區／範圍的顯示模式，不記住新 Session 授權。隱藏時 `/cmcp help` 仍能開啟完整選單；這些指令不呼叫模型。

`/cmcp on` 與 `/cmcp off` 只處理目前對話；`/cmcp set clean on` 等明示操作才修改共用控制。用 `/cmcp sources` 取得短期數字選項，再以 `/cmcp read 1` 正式讀取第一項；頁面有界，原文過長可帶頁碼，不將目前一頁說成全部 History。選項過期、換對話、控制世代或來源變更須重新列出，不能拿歷史選項自動授權。

薄列顯示啟用狀態、保存範圍、來源／Buffer／Pin 數量、共用控制及最近來源操作。「未知」表示目前沒有授權或可靠資料，與已核對的空集合不同。

按「查看狀態」開啟官方彈出層。摘要與控制、來源與原件、Buffer、Pin、回查與回執分頁保留既有入口。來源原文與圖片預覽須經目前授權及正式讀取；原件不存在、版本不符、撤權或 hash 不符時不提供有效圖片。

關閉彈出層、換分頁、展開原件與重新讀取都不建立提醒、不呼叫模型，也不刷新 User 原時間、最後互動時間或 Buffer TTL。若狀態操作回報錯誤，應依實際錯誤處理，不能以舊畫面宣稱資料仍有效。

## 保存位置與解除接線

目前正式資料根為 `cmcp-desktop-native\state\history`；圖片原件位於其 `media-originals` 下，包含原件 blob、來源紀錄及可用狀態。`cmcp-desktop-native\state\trace` 是必要接線 metadata，並非另一份圖片或私人全文資料庫。Harness 自有附件與聊天紀錄仍由宿主管理。

停止保存、Session OFF、工作區 OFF、Clean、Clear 與解除接線各自保留既有語意。Buffer 到期不刪 History 或圖片；Clear 不取消獨立 Pin；解除外掛登錄不刪已保存原件，也不清除宿主原生聊天。

以[正式資料匯出／驗證／還原命令](release-readiness.zh-TW.md)保留完整資料；還原只接受新目標，原文、媒體 blob、來源紀錄與版本關係需一併核對，且不恢復執行授權。單獨複製縮圖或描述不能還原原件。任何未經驗證的跨版本還原均不得稱為成功。檔案複製不取代讀取授權；日常查看仍走正式介面，不直接讀底層檔案繞過控制。

## 能力邊界

本頁限 PNG／JPEG 原件及日常介面；JPEG 有正常 Desktop 跨 Session 與視覺比較限定證據，PNG 原件保存另列離線證據。未新增音訊、影片、OCR、視覺相似搜尋、向量、資料庫遷移或外部推送。主動與 Pin 派送保留原控制，查看介面不開啟它們。原生模型圖片支援、CMCP 正式取回與語意比較各自驗收，不以其中一項成功代替其他項目。
