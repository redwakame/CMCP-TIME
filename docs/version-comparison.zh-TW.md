**0.1.1 不只是安裝說明的更新。** 它納入原文接續的累積改進，再補上四項既有功能的定點維護。下表以使用者能理解的行為說明差異，工程細節留在原始發布文件。

| 區域 | 0.1.0 的基礎 | 0.1.1 的增量 |
|---|---|---|
| 原文與時間 | 原件、角色、時間及來源關係；有界回查。 | 基礎保留，沒有以新摘要取代原件。 |
| 計畫與回報 | 已有時間、來源及接續入口。 | 累積 S1／S1-R1 改進，分開目前計畫與使用者回報，避免把意圖直接當成已發生事實。 |
| 局部修訂與理由 | 已有來源回查，不代表這次新增的表示與驗收當時已完成。 | 條件與明示適用對象分開；修改指定部分、保留其餘條件，分清新增理由、優先考量與明示撤回。 |
| 初始化 | 互動精靈及 `--answers` 已存在。 | 非 TTY／EOF 清楚處理；批次管線不支援，改用 `--answers`。沒選 Codex 就不探測或提示啟動它。 |
| 按需目前狀態 | 已有來源與控制基礎。 | 改善指定混合回報／指令情境的回饋與分頁完整取得，並保留未讀來源和真正歧義。 |
| 主動狀態 | 首次 OFF，既有 Buffer／Pin／勿擾與授權控制。 | 分清設定值、有效執行器、送達入口與候選；沒有新增一般主動政策。 |
| 發布與文件 | 四語文件、圖解、正式 GitHub／npm 0.1.0。 | 正式 GitHub 0.1.1、累積來源與修正後的發布對照。npm 是另一個需獨立確認的通道。 |

## 原則沒有改變

原文不被衍生整理取代；宿主的模型繼續推理；Codex 不是必要依賴。保存、追蹤、勿擾及外部執行授權仍分開。Apache-2.0、redwakame 署名與合法上游沿革保留。

## 不把局部通過寫成全部完成

H4 指定三項回報與完整投影分頁在新 Session 成立。正常鏈沒有走 resolution 分支，該分支由 13 項固定原件測試覆蓋；額外 r8 未進模型，不能稱全選取 READ-ALL。C27 163／236 容量限制及舊回執前像缺件保留。

本版未新增 Dots／Muse／Grok Bot 完整生命週期、全面跨雲、音訊／影片、向量或完整 24/7 代理，也未證明優於其他產品原生記憶。四語文件是資訊可用性，不是四語模型行為認證。

## 取得版本與更新

先依[首頁的固定 npm 版本安裝方式](../README.zh-TW.md#開始使用)或[安裝指南](npm-installation.md)選擇持久目錄。更新前備份，不直接刪除 History；安裝套件與升級宿主接線是不同操作。

GitHub 與 npm 成品的發布設定和文件可能不同，執行內容與來源映射請見各自發布紀錄。固定版本安裝不代表 GitHub 與 npm 的壓縮檔位元組相同；不要以 `latest` 代替固定來源。
