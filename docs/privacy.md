# Privacy, saving and user control

## What is preserved

When enabled and authorized, the Runtime records the text sources it actually receives, their roles, source identities and original times. Ordinary conversation need not enter Buffer to remain addressable. A reliable host may provide original storage; the reference local route uses its authorized History provider.

The source/time catalog and derived event/discussion state are not replacements for the original text. Buffer is an expiring working set, not the historical archive. Pins are explicit targets, not permission to ingest unrelated sources.

## What may leave the device

Inspect the route you enable. A configured remote model receives the bounded source/context selected for that request. A host-model route is subject to the host's own processing and privacy terms. Local source storage therefore does not by itself mean fully offline inference.

This source distribution contains no personal runtime root, credentials or authorization ledger. Cloud synchronization, cross-account sharing, behavior/sleep inference and raw-conversation telemetry are not enabled by this publication preparation. Do not treat a compatible host or a shared computer as implicit authorization to share another person's history.

## Controls are not interchangeable

- **OFF / Clean** limit augmentation according to their settings; they do not erase History.
- **Saving controls** govern new User/Assistant body capture. They do not revoke a model/host's independent transcript storage.
- **Buffer Clear** clears eligible Buffer state; it is not History deletion and does not cancel an independent Pin.
- **Revocation/cancellation** governs the relevant work/ticket; it cannot un-send content already delivered.
- **Pin completion** requires explicit completion or an agreed corresponding condition. A notification being sent is not completion.

Complete reference-History deletion and propagation through every derived layer is not implemented in this release candidate. Do not advertise Clear as that capability. Data remains subject to the actual provider, configuration and storage availability, not an unqualified permanent-retention guarantee.

## Safe troubleshooting

Keep sensitive originals local. Share minimal synthetic reproductions, version IDs and non-sensitive error codes. Check filenames, paths, images, metadata and snippets before sharing. Sanitized copies are not byte-identical original evidence; label replacements and do not use changed timestamps as proof of real elapsed time.

The project's `.gitignore` and package allowlist help exclude generated/private material. They are not a secret scanner or a substitute for reviewing the actual files and Git history to be published.
