# CMCP-TIME 0.1.0

[English](../README.md) · [繁體中文](../README.zh-TW.md) · [Español](../README.es.md) · [日本語](../README.ja.md)

## English

The first stable package combines the Skill-first core, authorized original text and image retrieval, original timestamps, optional compact controls, explicit in-app Pins, backup/restore, sequential host handoff, and optional MCP stdio/Streamable HTTP. Hermes CLI, Harness SDK/Desktop and Codex app-server evidence have different scopes; see the guides and capability matrix. It is not a claim of every agent, cloud service or 24/7 operation.

Install the fixed version with `npm install --global --prefix <persistent-prefix> @redwakame-skill/cmcp-time@0.1.0`. Keep data in a separate authorized workspace. The release targets both `latest` and `next` at 0.1.0; registry readback determines their actual state. The corresponding source tag is `v0.1.0`; main may later contain documentation changes. No automatic install/publish lifecycle scripts or provider change are introduced.
